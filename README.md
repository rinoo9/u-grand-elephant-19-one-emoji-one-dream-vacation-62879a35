# One Emoji, One Dream Vacation

A one-emoji entry for the make.fun bounty "One Emoji, One Dream Vacation": a single emoji standing in for a dream vacation.

The entry (round 2 revision — changed from round 1's 🏝️ desert island):

> 🏖️

A beach with an umbrella — sand, sea, and shade in one frame. The whole dream holiday, at a glance, like a postcard. The island said "escape"; the beach says "holiday" — the trip itself, doing nothing somewhere beautiful.

`main.py` writes the emoji to `/output/entry.txt` (UTF-8, no trailing newline).
